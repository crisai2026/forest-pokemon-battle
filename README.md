# 🌲 Forest Pokémon Battle 🌲

A two-player strategy game made by Theo.

## How to play
1. Each team (🔴 Red and 🔵 Blue) gets **20 points**.
2. Take turns picking Pokémon. Cheap ones let you have more; expensive ones are stronger.
3. Press **Start Battle!** and take turns moving and attacking on the forest board.
4. Knock out the other team to win!

Just open `index.html` in any web browser to play.
